# 🩺 Secure EHR Insight & Clinical Validator

**HIPAA-aware natural-language Q&A over patient records.** A clinician picks a patient and asks questions
("what was prescribed at discharge?"). The system retrieves that patient's records from Postgres (pgvector),
**redacts PHI before any LLM sees the text**, **blocks treatment/diagnosis/identity/prompt-injection requests**,
and **audit-logs every query**.

> Demo data is 100 % synthetic (generated by `scripts/01_generate_sample_data.py`). Not for real PHI - see
> [docs/COMPLIANCE_AND_LIMITATIONS.md](docs/COMPLIANCE_AND_LIMITATIONS.md).

## Architecture
```
Clinician ─► Streamlit UI ─► FastAPI /api/v1/chat {patient_id, messages}
                                │
   1. input guardrails  ────────┤  regex rules (+ optional NeMo/Colang): medical advice, PHI requests,
                                │  prompt injection, out-of-scope   → refuse, LLM never called
   2. embed question ───────────┤  hash (offline) or biomedical sentence-transformer (768-d)
   3. patient-scoped search ────┤  Postgres+pgvector: WHERE subject_id=:pid ORDER BY emb <=> :q  (cosine)
   4. PHI redaction ────────────┤  Presidio + custom SSN/MRN/address/clinician-title + hospital deny-list
   5. LLM (redacted text only) ─┤  any OpenAI-compatible API, or offline "mock"
   6. output redaction + audit ─┘  audit_log table: who/what/decision/counts (no raw PHI)
```
Full diagrams and flow paths: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Quickstart

**A. Docker (one command)** - needs Docker; first build downloads spaCy `en_core_web_lg` (~600 MB)
```bash
cp .env.example .env
docker compose up --build        # → http://localhost:8501   (data + embeddings load automatically)
```
**B. Local (no Docker)** - needs a Postgres 14+ with the `pgvector` extension
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && python -m spacy download en_core_web_lg
cp .env.example .env             # edit DATABASE_URL if needed
export PYTHONPATH=src
python scripts/bootstrap.py      # ingest sample data → pgvector schema → embeddings
uvicorn ehr.api:app --port 8000 &  &&  streamlit run ui/app.py
```
Run tests / measured metrics: `make test` · `make eval`

## Modes (all via `.env`)
| Setting | Offline demo (default) | "Real" mode |
|---|---|---|
| `LLM_PROVIDER` | `mock` (no key; extractive answer) | `openai` + `LLM_BASE_URL/KEY/MODEL` (DeepSeek, Groq, OpenAI, Ollama...) |
| `EMBED_BACKEND` | `hash` (lexical) | `st` + `pip install -r requirements-ml.txt` (semantic biomedical model) |
| `USE_NEMO` | `false` (deterministic rules) | `true` (adds NeMo Guardrails; experimental) |

## Measured results (synthetic data, reproducible with `make eval`)
| Metric | Result |
|---|---|
| PHI leak rate on 1,242 planted identifiers (`en_core_web_lg`) | **0.3 %** (4 leaks, all person names) |
| Same, `en_core_web_sm` | 1.8 % |
| Clinical terms surviving redaction (drug / dose / lab value) | **94.2 %** |
| Guardrail rule-suite (44 prompts) | 44/44 - *dev set, first run 43/44; not an independent benchmark* |
| Pipeline latency p50, mock LLM, single patient | ~175 ms (redaction is ~2/3 of it) |
| Tests | 55 passing (unit + DB/API integration) |
